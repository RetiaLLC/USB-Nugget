CATSCRATCH GUIDE

Keystroke, mouse and loop commands. One command per line.

REM or //               comment
STRING hi   (or TYPE)   type a string
STRINGLN hi             type a string, then Enter
<KEY> / CTRL c / GUI r  keys & combos (ENTER TAB ESC F1..)
DELAY 500   (or WAIT)   pause milliseconds
LOCALE DE               layout: EN ES DE FR PT
LED R                   ear colour R G B Y C M W
SCREEN text             show text on the OLED

MOUSE_MOVE 40 -20       move cursor (x y, any range)
MOUSE_CLICK L|R|M       click left / right / middle
MOUSE_DOUBLE            double-click
MOUSE_SCROLL 3          scroll (negative = down)
JIGGLE 60               anti-idle wiggle, 60 times

REPEAT 5                repeat the previous line 5x
LOOP 3                  repeat the block below 3 times
  STRING spam
ENDLOOP                 (optional: without it, LOOP
                         repeats to the end of the file)

IF_OS WINDOWS           run a block only on that OS
  STRING notepad
ELSE                    OS = WINDOWS MACOS LINUX
  STRING gedit
END_IF
$_OS                    inserts the detected OS name
